    Sources & caveats

      • One-stop = in-person early voting (ballot type "EARLY VOTING" in 2026, "ONE-STOP" in earlier files), accepted ballots only, counted on the day cast. Mail = mail ballots accepted (including cured), counted on the return date.
      • Past-cycle files are the final post-election versions. Ballots later spoiled or rejected, or from voters since removed, can differ slightly from what was reported live at that time.
      • Party and race are as recorded in each file (a voter's registration then). Unaffiliated voters are now the largest NC group, so D/R shares alone understate turnout among UNA.
      • The 2026 file currently lists only ballots that have been returned or cast, so outstanding mail requests are not available for 2026 and mail requests are not compared.
      • Days-out = Election Day minus the date the ballot was cast. The state's file is posted early each morning and runs through the previous day.

      Law changes that affect comparisons

      North Carolina's rules changed in 2023–2024, so 2018 and 2022 were run under different rules than 2026.

      • 2023 · Senate Bill 747 (S.L. 2023-140): mail ballots must arrive by 7:30 p.m. on Election Day; the old 3-day grace period for postmarked ballots ended (military/overseas excepted). Same-day registrants during early voting now cast a "retrievable" ballot that can be pulled if address verification fails. NC General Assembly bill summary · bill text
      • Photo ID has been required since the 2024 primaries (not in place in 2018 or 2022). NC State Board of Elections
