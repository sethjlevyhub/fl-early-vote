    Sources & caveats

      • Iowa counts in-person early voting as absentee voting, so "received" = mail ballots received + in-person early votes. Past-cycle reports don't split out the method statewide.
      • 2018 isn't directly comparable: Iowa's early-voting window was 29 days (opened Oct 8, 2018). It was cut to 20 days starting in 2022, so 2018 had a much bigger head start at the same days-out.
      • Reports post on weekday mornings (data pulled ~3–4 AM ET) and replace the previous day's file. Each point is dated by the report date. Past cycles come from SOS archive PDFs that bundle every daily report.
      • Party = voter registration (Democrat, Republican, No Party; Libertarian/Green/other grouped as Other). Party splits are shown only where the county lines add up exactly to the state total.
      • When the SOS posted two versions on the same date, the later (larger) one is used.

      Law changes that affect comparisons

      Iowa shortened its early-voting window in 2021, so 2018 had a longer runway than 2022 and 2026.

      • 2021 · Senate File 413: early in-person voting and mailing of absentee ballots now start 20 days before Election Day (was 29); absentee ballots must be received by the county auditor when polls close on Election Day; counties can't mail absentee request forms unless the voter asks.
